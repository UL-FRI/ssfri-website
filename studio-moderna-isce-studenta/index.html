Studio Moderna išče študenta

21. februar 2017Nerazvrščeno

Studio Moderna išče študenta za mesto sistemskega administratorja (začetnik).

Znanja in pričakovanja:
 poznavanje in zanimanje za sistemsko programske opremo (Windows),
 poznavanje in zanimanje za področje MS in/ali Linux strežniške platforme,
 zanimanje za področje: WAN in LAN infrastruktura, MS SystemCenter (SCCM, SCOM, VMM), Skype 4 Business, MS SQL, MS IIS, MS DirectAccess, MS DPM, MS HyperV, VMWare Datacenter / Cloud / Application platform, diskovni sistemi – (vse z open source ali proprietary orodji za upravljanje),
 zanimanje za programiranje s skriptnimi jeziki, ki omogočajo avtomatizacijo rutinskih opravil (npr. Powershell, python, perl…),
 aktivno znanje angleškega jezika.

Več informacij tukaj: Sistemski administrator začetnik_februar 2017
