Iščemo sodelavca, ki pozna delovanje spletnih tehnologij, ter ogrodje ReactJS/Redux.\
**Pričakujemo:**\
– Najmanj V. stopnjo izobrazbe računalniške ali sorodnih smeri\
– Samostojnost, samoinciativnost, zanesljivost\
– Aktivno znanje angleškega jezika\
– Sledenje standardom IT razvoja\
– HTML 5\
– JavaScript ES6/7\
– SCSS\
– Webpack / NPM (osnovno znanje)\
– ReactJS + Redux (osnovno znanje)\
**Priporočena znanja:**\
– Docker delovanje in upravljanje kontejnerjev\
– Python 3 ter Flask ogrodje\
– SQL in Redis delovanje\
– Linux okolje in uporaba bash lupine
