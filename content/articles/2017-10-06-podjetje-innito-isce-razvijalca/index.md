Kot razvojni inženir boste sodelovali pri razvoju informacijskih sistemov, predvsem novih funkcionalnih modulov in samostojnih aplikacij. Delo zajema implementacijo in testiranje programske opreme po projektni dokumentaciji, sodelovanje s projektno ekipo in druge dopolnjujoče dejavnosti.

*Od novih sodelavcev pričakujemo željo po razvijanju inovativnih oblačnih rešitev s sodobno tehnologijo, dobro analitično sposobnost, pripravljenost za učenje novih tehnologij in timsko delo. Predhodne delovne izkušnje so zaželene, vendar niso pogoj.*

**Željena razvojno-tehnična znanja:**

- Razvojno okolje .NET in programski jezik Microsoft C#
- JavaScript (jquery, json)
- Microsoft SQL Server
- Zaželjene izkušnje z ASP.NET MVC in Microsoft Dynamics 365 (CRM)
- Znanje tujih jezikov: angleški jezik tekoče/dobro
- Vozniški izpit B kategorije
