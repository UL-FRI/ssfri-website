Podjetje PartIt d.o.o. vabi v ekipo nove sodelavce, s katerimi bo uspešno in kvalitetno obvladoval projekte v javni upravi in gospodarstvu. Delo bi lahko nastopili takoj.

Potrebna znanja / izkušnje so:

– Java 2EEE back-end & front-end programiranje – vsaj 3 leta programiranja

– Razvoj spletnih servisov

– Poznavanje podatkovnih baz Oracle in MS SQL / MySQL

– Zaželena izkušnje razvoja Java aplikacij z uporabo digitalnih potrdil (ePodpisovanje in kriptiranje)

– Certifikat Java je zelo zaželen
