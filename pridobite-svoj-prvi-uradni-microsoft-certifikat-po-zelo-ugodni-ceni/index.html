Pridobite svoj prvi uradni Microsoft certifikat po zelo ugodni ceni

13. april 2017Nerazvrščeno

Zaradi pomanjkanja certificiranih Microsoft strokovnjakov v Sloveniji, izobraževalni center Housing organizira izobraževanja za pridobitev naziva Microsoft Technology Associate (MTA).
Cena posameznega tečaja znaša 111 EUR z DDV oziroma 275 EUR z DDV za paket vseh treh tečajev. Omogočamo 89% popust na redno ceno posameznega tečaja, ki znaša 976 EUR.
Pridobitev naziva MTA strokovnjaka za Windows Server Administration Fundamentals, Networking Fundamentals ter Security Fundamentals vam prinaša naslednje prednosti:

  • Prednost pri iskanju vaše prve zaposlitve,
  • Prvi certifikat na poti gradnje vaše kariere,
  • Primeren za vse, ki se želite certificirati v Microsoft programskem okolju,
  • MTA naziv vam tako kot vsi ostali Microsoft nazivi, ki jih pridobite, ostane za vedno,
  • Primeren za vse, ki želite potrditi ali obnoviti že osvojena znanja.
