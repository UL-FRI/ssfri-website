Tekmovanje Google Hash Code na FMF

19. januar 2017Nerazvrščeno

Na Fakulteti za matematiko in fiziko bo v soboto, 23.2.2017, v večernih urah (od 18:30 do 22:30) potekalo tekmovanje Google Hash Code.
Hash Code je online tekmovanje ekip z 2-4 člani, ki ga vsako leto organizira Google.

Več o dogodku tukaj: https://www.facebook.com/events/213580022381974/
