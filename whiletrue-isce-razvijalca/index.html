Podjetje While True išče razvijalca

7. december 2015Kariera

Iščemo razvijalca za dolgoročno sodelovanje pri razvoju storitev in aplikacij.

Pričakujemo nekajletne izkušnje z razvojem programske opreme in dobro pisno znanje angleškega jezika. Komunikacija s strankami poteka v angleškem jeziku.

Zaželena znanja:

* Front-end: javascript, HTML, CSS
* Back-end: Java in/ali .NET

Bonus znanja:
* Spring framework, posebej Spring Boot
* ASP.NET MVC
* Poznavanje procesa razvoja: unit testing, agile, continuous integration, build tools
* javascript SPA: Ember.js, LESS/SASS, gulp, grunt, CoffeeScript,…
* JIRA
* TeamCity
* Jenkins
* mobilne aplikacije: Android in iOS

Delo poteka v Ljubljani. Ponujamo redno zaposlitev, delo po pogodbi, prek študenskega servisa ali po dogovoru.

Plačilo po dogovoru, glede na znanje in izkušnje.
